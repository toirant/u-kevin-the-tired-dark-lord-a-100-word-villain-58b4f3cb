A single monologue of about 100 words, spoken by Lord Ashenmar, keeper of the
Ember Crown for three hundred years, on the night of the eclipse ritual —
the seven seals, the choir of drowned kings humming under the floor, a
kingdom to unmake before the candles burn down.

His tiredness is never announced. It lives in the voice: the pauses, the
trailing thoughts, the small deflections ("never mind", "where was I?"),
while the scheme stays fully in motion and the last line lands its sting.

## Run

```sh
node main.ts
```

This writes the monologue to `/output/entry.txt` (97 words, 503 characters),
validating in code that it is UTF-8 text of 1–600 characters, not
whitespace-only, about 100 words, and never plainly states weariness.
